How to enable email sending

Emails are sent from ankit.kumar.prasad.50@gmail.com using a Google App Password (a special 16-character password just for this app — never your real Gmail password).

1 · Turn on 2-Step Verification

Sign in to that Google account and enable 2-Step Verification at myaccount.google.com/security. (App Passwords require it.)

2 · Create an App Password

Go to myaccount.google.com/apppasswords, name it “Vidya Vriksh”, and copy the 16-character password it gives you.

3 · Save it securely on the server

In a terminal, in the Tuition Website.Server folder, run these (the App Password stays only on this machine, never in the code):

dotnet user-secrets set "Email:Sender" "ankit.kumar.prasad.50@gmail.com"
dotnet user-secrets set "Email:AppPassword" "your16charapppassword"
dotnet user-secrets set "Email:FromName" "Vidya Vriksh Tuition"

4 · Restart the app (in Development mode)

Run the server with dotnet run (the default Development environment loads these secrets), then refresh this page — the status above should turn green. Now the “Email report to parent” buttons will work.
